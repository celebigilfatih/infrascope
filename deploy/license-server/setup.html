InfraScope Merkezi Lisans Server Kurulumu

Bu rehber, https://coolify.webmahsul.com.tr üzerinde merkezi lisans server'ı lisans.webmahsul.com.tr adresinde yayına almak ve Coolify içindeki mevcut PostgreSQL resource'unu kullanmak içindir.

Domainhttps://lisans.webmahsul.com.tr
Deploymenthttps://coolify.webmahsul.com.tr
DatabaseCoolify PostgreSQL resource

1. DNS Kaydı

Domain panelinde A kaydını Hostinger VPS IP adresine yönlendir.

lisans.webmahsul.com.tr  A  SUNUCU_IP_ADRESI
DNS oturması birkaç dakika ile birkaç saat arasında sürebilir. Coolify tarafında domain eklemeden önce kayıt çözülmeye başlamış olmalı.

2. Coolify PostgreSQL Bilgilerini Hazırla

Coolify panelinde mevcut PostgreSQL resource'una gir ve internal connection bilgilerini al. InfraScope lisans server aynı Coolify network'ünde çalışacağı için public database URL değil, internal host/service adı kullanılmalıdır.

Gerekli değerCoolify'da karşılığı
DB_HOSTPostgreSQL resource internal hostname / service name
DB_PORTGenelde 5432
POSTGRES_USERPostgreSQL user
POSTGRES_PASSWORDPostgreSQL password
POSTGRES_DBLisans server için kullanılacak database
Eğer Coolify PostgreSQL resource içinde yeni database oluşturabiliyorsan infrascope_license adını kullan. Yoksa mevcut database adını DATABASE_URL içinde aynı şekilde kullan.

3. Coolify PostgreSQL Bağlantısını Test Et

PostgreSQL Coolify resource olarak çalışıyorsa genellikle postgresql.conf veya pg_hba.conf düzenlemen gerekmez. Aynı Coolify private network içinden internal hostname ile erişilir. 

DATABASE_URL=postgresql://USER:PASSWORD@DB_HOST:5432/DB_NAME?schema=public
Eğer PostgreSQL Coolify içinde değil de doğrudan VPS host üzerinde kuruluysa, aşağıdaki alternatif host PostgreSQL ayarlarını kullan.

Alternatif: Host üzerinde kurulu PostgreSQL

PostgreSQL sunucuda kurulu olduğu için Coolify container'ı ona localhost ile erişemez. Container içinden host makineye erişmek için host.docker.internal kullanacağız.

postgresql.conf

PostgreSQL konfigürasyon dosyasını bul:

sudo -u postgres psql -c "SHOW config_file;"

Dosyada listen_addresses değerini düzenle:

sudo nano /etc/postgresql/*/main/postgresql.conf
listen_addresses = '*'

pg_hba.conf

pg_hba.conf dosyasını bul:

sudo -u postgres psql -c "SHOW hba_file;"

Docker bridge/Coolify container ağından gelen bağlantıya izin ver:

sudo nano /etc/postgresql/*/main/pg_hba.conf
# Docker / Coolify containers
host    infrascope_license    infrascope_license    172.16.0.0/12    scram-sha-256
host    infrascope_license    infrascope_license    192.168.0.0/16   scram-sha-256
host    infrascope_license    infrascope_license    10.0.0.0/8       scram-sha-256

PostgreSQL'i yeniden başlat:

sudo systemctl restart postgresql
Daha dar bir IP aralığı biliyorsan geniş private network aralıkları yerine sadece Coolify Docker network subnet'ini yazman daha iyidir.

4. Sunucu Firewall Kontrolü

PostgreSQL portunu internete açma. Sadece lokal/Docker private ağdan erişilebilir olmalı. UFW kullanıyorsan dış dünyaya 5432 açma. 

sudo ufw status
sudo ss -lntp | grep 5432
Coolify container aynı VPS üzerinde çalıştığı için PostgreSQL'i public IP'ye açmadan host.docker.internal:5432 üzerinden bağlanacağız.

5. Coolify Resource Oluştur

  1. https://coolify.webmahsul.com.tr adresinde ilgili projeye gir.
  2. New Resource seç.
  3. Docker Compose resource oluştur.
  4. Repository olarak InfraScope repo'sunu bağla.
  5. Compose path olarak şunu gir:
deploy/license-server/docker-compose.yml
Müşteri kurulumu için olan deploy/docker-compose.yml dosyasını burada kullanma. Merkezi lisans sunucusu için sadece deploy/license-server/docker-compose.yml kullanılacak.

6. Coolify Environment Variables

Coolify resource içine aşağıdaki environment değerlerini gir. PostgreSQL değerlerini Coolify PostgreSQL resource'unun internal connection bilgilerine göre doldur. 

APP_URL=https://lisans.webmahsul.com.tr
NEXTAUTH_URL=https://lisans.webmahsul.com.tr
APP_PORT=3000
APP_NAME=InfraScope License Server

DEPLOYMENT_MODE=license-server
LICENSE_SERVER_MODE=true

DB_HOST=COOLIFY_POSTGRES_INTERNAL_HOST
DB_PORT=5432
POSTGRES_USER=infrascope_license
POSTGRES_PASSWORD=BURAYA_COK_GUCLU_SIFRE
POSTGRES_DB=infrascope_license
DATABASE_URL=postgresql://infrascope_license:BURAYA_COK_GUCLU_SIFRE@COOLIFY_POSTGRES_INTERNAL_HOST:5432/infrascope_license?schema=public

NEXTAUTH_SECRET=OPENSSL_ILE_URET
LICENSE_JWT_SECRET=OPENSSL_ILE_URET

REGISTRY=ghcr.io/celebigilfatih
VERSION=1.0.0

Secret üretmek için:

openssl rand -base64 32
Repo içinde deploy/license-server/coolify.env.example dosyası da aynı değerler için hazır şablon olarak eklendi.

8. Deploy ve Kontrol

Coolify üzerinden deploy başlat. Deploy bittikten sonra health endpoint'i kontrol et:

curl https://lisans.webmahsul.com.tr/api/health

İlk kurulum için:

https://lisans.webmahsul.com.tr/setup

Admin hesabı oluşturduktan sonra merkezi lisans paneli:

https://lisans.webmahsul.com.tr/license-admin

9. İlk Lisansı Oluştur

/license-admin sayfasında Create License ile müşteri lisansı oluştur.

Müşteriye sadece üretilen lisans key verilir. Müşteri kurulumundaki env şöyle olmalı:

LICENSE_SERVER_URL=https://lisans.webmahsul.com.tr
LICENSE_KEY=IS-2026-XXXX-XXXX-XXXX

10. Hızlı Sorun Giderme

BelirtiKontrol
App database'e bağlanamıyor Coolify PostgreSQL internal hostname, DATABASE_URL, user/password ve resource network bağlantısını kontrol et.
/api/license/activate 404 dönüyor DEPLOYMENT_MODE=license-server ve LICENSE_SERVER_MODE=true env değerlerini kontrol et.
/license-admin açılmıyor Önce /setup ile ADMIN oluştur, sonra login ol. Ayrıca server mode env'leri doğru olmalı.
TLS/domain hatası DNS A kaydı, Coolify domain ayarı ve proxy sertifikasını kontrol et.
