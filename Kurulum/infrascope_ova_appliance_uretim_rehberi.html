2. Ubuntu VM hazırlığı

Ubuntu Server 24.04 LTS güncellenmiş olmalıdır. Önerilen kaynaklar 2 vCPU, 8 GB RAM ve en az 80 GB disktir.

2.1 Araçlar

hostnamectl && ip addr && df -h && free -h && timedatectl
sudo apt install -y ca-certificates curl gnupg openssl jq ufw tar unzip

2.2 Docker Engine ve Compose

sudo install -m 0755 -d /etc/apt/keyrings
curl -fsSL https://download.docker.com/linux/ubuntu/gpg | sudo gpg --dearmor -o /etc/apt/keyrings/docker.gpg
sudo chmod a+r /etc/apt/keyrings/docker.gpg
echo "deb [arch=$(dpkg --print-architecture) signed-by=/etc/apt/keyrings/docker.gpg] https://download.docker.com/linux/ubuntu $(. /etc/os-release && echo \"$VERSION_CODENAME\") stable" | sudo tee /etc/apt/sources.list.d/docker.list > /dev/null
sudo apt update && sudo apt install -y docker-ce docker-ce-cli containerd.io docker-buildx-plugin docker-compose-plugin
sudo systemctl enable docker && sudo systemctl start docker
sudo usermod -aG docker "$USER" && newgrp docker
docker --version && docker compose version && docker run hello-world

2.3 Firewall

sudo ufw allow OpenSSH && sudo ufw allow 8170/tcp && sudo ufw --force enable && sudo ufw status

3. Production image hazırlığı

Bu bölüm geliştirme bilgisayarında, müşteri Ubuntu VM’inin dışında çalıştırılır. Kaynak branch release/v1.0.0, image tag’i 1.0.0 olmalıdır.

git fetch origin && git checkout -B release/v1.0.0 origin/release/v1.0.0
npm run type-check && npm run security:tls-check && npm run build
docker build -t ghcr.io/celebigilfatih/infrascope:1.0.0 .
mkdir -p dist && docker save ghcr.io/celebigilfatih/infrascope:1.0.0 -o dist/infrascope-1.0.0.tar
Image etiketi eşleşmeliCompose ghcr.io/celebigilfatih/infrascope:1.0.0 bekler. Farklı tag kullanılırsa appliance image’ı bulamaz.

4. Appliance dosyalarını aktarma

Asset paketi source code içermez; compose, installer, update scriptleri ve appliance komutlarını içerir.

VERSION=1.0.0 bash scripts/package-appliance-assets.sh
scp dist/infrascope-appliance-1.0.0.tar.gz ubuntu@VM_IP:/tmp/
scp dist/infrascope-1.0.0.tar ubuntu@VM_IP:/tmp/

Ubuntu VM’de:

cd /tmp && tar -xzf infrascope-appliance-1.0.0.tar.gz && cd infrascope-appliance-1.0.0
sudo ./INSTALL_ON_VM.sh
sudo mkdir -p /opt/infrascope/images && sudo cp /tmp/infrascope-1.0.0.tar /opt/infrascope/images/infrascope-1.0.0.tar
ls -lh /opt/infrascope/images

5. Ayrı doğrulama klonu

Golden VM’i doğrudan kurup temizlemeyin. Appliance dosyaları kurulduktan sonra VM’in klonunu oluşturun; test işlemleri bu klonda yapılır.

5.1 Kurulum ve test

sudo infrascope-setup
infrascope-status
docker compose ps
curl -sf http://localhost:8170/api/health/ready
docker compose logs --tail=100 app

Geçici/demo lisansı ve klon URL’ini girin. /setup, ilk admin, login/logout ve /settings/license kontrol edilmelidir.

  • PostgreSQL ve app healthy.
  • /setup açılıyor.
  • İlk admin oluşturuluyor ve login yapılabiliyor.
  • Lisans ACTIVE gösteriyor.
  • Reboot sonrası servisler otomatik kalkıyor.

6. Golden VM son kontrolü

Doğrulama başarılıysa klonu kapatın. Golden VM’de yalnızca appliance dosyaları ve image tar bulunmalıdır.

  • infrascope-setup çalıştırılmadı.
  • /opt/infrascope/.env bulunmuyor.
  • data/machine-id ve data/license-cache boş.
  • PostgreSQL müşteri verisi ve volume’u yok.
  • Shell history içinde lisans key veya parola yok.
  • Merkezi lisans server dosyaları kopyalanmadı.
sudo test ! -f /opt/infrascope/.env && echo ".env yok: OK"
sudo find /opt/infrascope/data -type f -print
docker ps -a && docker volume ls

7. VMware OVF/OVA export

sudo shutdown -h now
  1. VMware’de Export OVF Template veya Export as OVA seçin.
  2. Dosya adını InfraScope-Appliance-1.0.0.ova yapın.
  3. Export sonrası hash değerini kaydedin.
shasum -a 256 InfraScope-Appliance-1.0.0.ova

8. Yayın kontrol listesi

  • OVA import ediliyor.
  • VM 2 vCPU, 8 GB RAM ve 80 GB disk ile açılıyor.
  • 8170/tcp erişilebilir.
  • İlk kurulum yalnızca müşteri tarafından yapılabiliyor.
  • Image tar doğru tag ile yüklü.
  • OVA’da source code, Git, npm ve merkezi license server yok.
  • Müşteriye lisans key’i ve müşteri rehberi teslim edildi.
