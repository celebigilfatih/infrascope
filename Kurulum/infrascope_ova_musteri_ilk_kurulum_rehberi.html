1. Gereksinimler

Bu rehber hazır OVA’yı kuran müşteri IT ekibi içindir. Müşteri VM’ine Git, Node.js, npm, kaynak kod veya merkezi lisans sunucusu kurulmaz.

İhtiyaçÖneri

Merkezi lisans sunucusuYalnızca https://lisans.webmahsul.com.tr adresine bağlanılır. Bu sunucunun Docker/VM dosyaları müşteriye verilmez.

2. OVA’yı VMware’e import edin

2.1 Import

  1. VMware arayüzünde Deploy OVF Template veya Import OVA seçin.
  2. Size verilen InfraScope-Appliance-1.0.0.ova dosyasını seçin.
  3. VM adını ve datastore’u belirleyin.
  4. Uygulama sunucusunun bağlı olduğu network port group’u seçin.
  5. Disk formatını ortamınıza uygun seçin ve import işlemini tamamlayın.
  6. VM’i başlatın; console ekranından Ubuntu’nun açılmasını bekleyin.
Snapshot önerisiİlk setup tamamlanmadan önce, gerekiyorsa temiz import noktasını geri dönüş amacıyla snapshot olarak saklayın.

3. Ağ ve IP kontrolü

VM console’unda Ubuntu kullanıcınızla oturum açın. DHCP ile gelen IP’yi öğrenin veya kurum standardınıza göre statik IP tanımlayın.

ip addr
ping -c 3 <gateway-ip>
curl -I https://lisans.webmahsul.com.tr

Kurumsal firewall üzerinde istemcilerin VM’e erişeceği 8170/tcp portunu açın. VM içinde UFW kullanılıyorsa:

sudo ufw allow 8170/tcp
sudo ufw status

4. İlk başlatma

4.1 Appliance setup komutu

sudo infrascope-setup

Script lisans key’i, uygulama URL’sini ve portu sorar. Aşağıdaki değerleri kullanın:

SoruDeğer
License keyInfraScope sağlayıcısının size verdiği key
Application URLhttp://VM_IP:8170
Application port8170

Script yerel Docker image’ını yükler, PostgreSQL ve uygulama için kalıcı alanları hazırlar, gizli değerleri üretir ve servisleri başlatır.

Varsayılan kullanıcı yokturKurulumdan sonra ilk admin hesabını tarayıcıdaki setup wizard’da siz oluşturursunuz. Hazır bir admin şifresi kullanılmaz.

5. Setup wizard ve ilk login

Kurulum tamamlandıktan sonra aynı ağdaki bilgisayardan şu adresi açın:

http://VM_IP:8170/setup
  1. Lisans aktivasyonunu tamamlayın.
  2. Firma/organizasyon bilgilerini girin.
  3. İlk ADMIN hesabını oluşturun.
  4. Login ekranına yönlenin ve belirlediğiniz bilgilerle giriş yapın.

İlk admin e-posta ve şifresini kurumunuzun parola politikasına göre belirleyin. Şifreyi kurulum ekibiyle paylaşmayın.

6. Kurulumu doğrulayın

VM console’unda aşağıdaki kontrolleri çalıştırın:

sudo infrascope-status
cd /opt/infrascope
docker compose ps
curl -sf http://localhost:8170/api/health/ready
  • □ app ve postgres servisleri çalışıyor.
  • □ Readiness endpoint’i başarılı cevap veriyor.
  • □ Dashboard açılıyor.
  • □ /settings/license ekranında lisans ACTIVE görünüyor.
  • □ İlk cihaz ve gerekiyorsa NMS izleme ayarı eklenebiliyor.
  • □ Merkezi panelde aktivasyon kaydı oluşuyor.

Logları görmek için:

cd /opt/infrascope
docker compose logs --tail=100 app

7. İlk kullanım sırası

  1. Locations: bina, kat, oda ve kabinet yapısını oluşturun.
  2. Devices: envanter cihazlarını ekleyin ve cihaz bilgilerini düzenleyin.
  3. NMS İzlenen Cihazlar: envanterdeki cihazı izlemeye alın; SNMP/SSH bilgilerini kaydedin.
  4. Network: bina bağlantılarını ve topolojiyi kontrol edin.
  5. Settings > Alerts: SMTP ve bildirim tercihlerini kurum politikanıza göre yapılandırın.

8. Offline image güncellemesi

Güncelleme paketi size yeni sürüm image tar dosyası olarak verilir. Örneğin infrascope-1.0.1.tar dosyasını VM’e aktarın:

sudo mkdir -p /opt/infrascope/images
sudo cp infrascope-1.0.1.tar /opt/infrascope/images/infrascope-1.0.1.tar
sudo infrascope-update 1.0.1
sudo infrascope-status
curl -sf http://localhost:8170/api/health/ready
Veritabanını silmeyindocker compose down -v komutu PostgreSQL verisini silebilir. Güncellemeden önce VM snapshot veya kurum yedekleme politikanızı uygulayın.
