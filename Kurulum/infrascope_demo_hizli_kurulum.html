InfraScope Demo Runbook

Demo Günü Hızlı Kurulum Rehberi

Bu doküman, müşteri sunucusunda InfraScope on-prem demo kurulumunu hızlı ve doğru yapmak için hazırlanmıştır.

Lisans sunucusuhttps://lisans.webmahsul.com.tr
Önerilen demo portu8170
Kurulum modeliDocker ile tek müşteri / tek tenant
Default adminYok, ilk admin setup wizard içinde oluşturulur

En Önemli Mantık

Müşteri sunucusu InfraScope kaynak kodunu indirmez. Müşteri sadece küçük kurulum dosyalarını alır. Gerçek uygulama, hazır Docker image olarak registry'den çekilir.
Parça Nereden Gelir? Ne İşe Yarar?
Kurulum dosyaları deploy/ klasörü veya private installer repo Compose, env örneği, install/update scriptleri
InfraScope uygulaması ghcr.io/celebigilfatih/infrascope:1.0.0 Hazır build edilmiş uygulama container image'ı
Lisans doğrulama https://lisans.webmahsul.com.tr Activation, validate, heartbeat
Müşteri verisi Müşteri sunucusundaki PostgreSQL container Cihaz, lokasyon, kullanıcı ve alarm verisi

Demo Öncesi Hazırlık

  1. Merkezi lisans paneline gir. 
    https://lisans.webmahsul.com.tr/license-admin
  2. Demo lisansı oluştur. 
    Company: Müşteri firma adı
Contact: Müşteri yetkilisi
Email: Müşteri emaili
Tier: STANDARD
Max Devices: 250
Max Users: 10
Days: 30
Activation Limit: 1
Notes: Demo / POC
  3. Oluşan lisans key'i not al. 
    LICENSE_SERVER_URL=https://lisans.webmahsul.com.tr
LICENSE_KEY=IS-2026-XXXX-XXXX-XXXX

Müşteri Sunucusunda Ön Kontrol

docker --version
docker compose version
docker info
curl -I https://lisans.webmahsul.com.tr
ss -ltnp | grep ':8170' || true
  • Docker çalışıyor olmalı.
  • Docker Compose v2 çalışıyor olmalı.
  • Müşteri sunucusundan lisans sunucusuna erişim olmalı.
  • 8170 portu boş veya farklı bir port seçilmiş olmalı.

Kurulum Dosyaları

Müşteri sunucusundaki kurulum klasöründe şu dosyalar olmalı:

docker-compose.yml
env.example
install.sh
update.sh
INSTALL.md
Müşteriye merkezi lisans server dosyaları verilmez. deploy/license-server müşteri paketinde olmamalıdır.

Kurulumu Başlat

mkdir infrascope
cd infrascope

# Kurulum dosyalarını bu klasöre koyduktan sonra:
cp env.example .env
chmod +x install.sh update.sh
./install.sh
Bazı paketlerde dosya adı .env.example olabilir. Bu durumda komut cp .env.example .env olarak çalıştırılır. Başında nokta olan dosyalar Windows/macOS tarafında gizli görünebilir.

Script sorularında şu değerleri gir:

License key: IS-2026-XXXX-XXXX-XXXX
App URL: http://SUNUCU_IP:8170
Host port: 8170

Script otomatik üretir:

  • NEXTAUTH_SECRET
  • POSTGRES_PASSWORD
  • data/license-cache
  • data/machine-id

Docker Image Konusu

docker-compose.yml uygulamayı şu image'dan çeker:

ghcr.io/celebigilfatih/infrascope:1.0.0
Eğer GHCR package private ise müşteri sunucusunda önce docker login ghcr.io gerekir. Ya da image/package GitHub Packages tarafında public yapılmalıdır.

Private image ise login örneği

docker login ghcr.io
# Username: GitHub kullanıcı adı
# Password: GitHub fine-grained token veya classic PAT

Kurulum Sonrası Kontrol

docker compose ps
curl -sf http://localhost:8170/api/health/ready
docker compose logs -f app

Beklenen:

  • postgres container healthy olmalı.
  • app container up/healthy olmalı.
  • Ready endpoint hata vermemeli.

İlk Açılış

Browser'dan aç:

http://SUNUCU_IP:8170/setup

Setup wizard akışı:

  1. Lisans aktivasyonu yapılır.
  2. Firma bilgisi girilir.
  3. İlk admin hesabı oluşturulur.
  4. Login ekranına yönlenir.
Default kullanıcı adı veya şifre yoktur. İlk admin hesabını müşteri kendi belirler.

Demo İçinde Gösterilecekler

  • Dashboard açılıyor.
  • Locations, Racks, Devices ekranları açılıyor.
  • /settings/license içinde lisans durumu görünüyor.
  • Merkezi panelde activation count 1 görünüyor.

Sorun Çıkarsa Hızlı Bakış

Sorun Kontrol Çözüm
Image çekilemiyor docker pull ghcr.io/celebigilfatih/infrascope:1.0.0 GHCR public yapılır veya docker login ghcr.io yapılır.
Lisans aktivasyonu başarısız curl -I https://lisans.webmahsul.com.tr Network/DNS/firewall kontrol edilir; lisans key doğru mu bakılır.
Port açılmıyor ss -ltnp | grep ':8170' Boş port seçilir veya firewall açılır.
App ayağa kalkmıyor docker compose logs -f app Env, DB, migration ve image erişimi kontrol edilir.
Activation limit dolu Lisans panelinde activation count Eski activation deactivate edilir veya limit artırılır.

Fallback Demo Planı

Müşteri sunucusunda Docker, network veya image erişimi sorun çıkarırsa demoyu local çalışan instance üzerinden göster. 
http://localhost:8170

Müşteriye şu şekilde anlat:

Kurulum modeli aynı. Şu an ürün akışını local on-prem instance üzerinden gösteriyoruz. Müşteri sunucusunda Docker image erişimi açıldığında aynı kurulum paketiyle production/demo instance ayağa kalkacak.

Demo Cümlesi

InfraScope müşterinin kendi sunucusunda Docker ile çalışır. Müşteri verisi kendi PostgreSQL ortamında kalır. Lisans sadece merkezi sunucumuzdan doğrulanır. Merkezi lisans sunucusu müşteriye kurulmaz.
